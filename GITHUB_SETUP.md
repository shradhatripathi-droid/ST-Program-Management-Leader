# How to Share This on GitHub

## Push to ST-Program-Management-Leader

```bash
cd ~/Projects/program-management-leader
git remote set-url origin https://github.com/shradhatripathi-droid/ST-Program-Management-Leader.git
git add index.html experience-detail_5.html index-v2.html README.md .nojekyll assets/ open-portfolio.sh
git commit -m "Publish program management leader portfolio"
git push -u origin main
```

## GitHub Pages

1. Open [Repository Settings ? Pages](https://github.com/shradhatripathi-droid/ST-Program-Management-Leader/settings/pages)
2. Source: **Deploy from branch**
3. Branch: **`main`** / **`/ (root)`**
4. Live site: `https://shradhatripathi-droid.github.io/ST-Program-Management-Leader/`
